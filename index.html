Top Contributing Indicators

How it works: This calculator analyzes all 26 recession indicators below using a weighted scoring algorithm.

The Math: Each indicator is assigned a status (Good = 0 points, Warning = 50 points, Bad = 100 points) and a weight based on reliability. The weighted average is calculated as: Probability = Σ(Status × Weight) / Σ(Weights)

Weights: Official indicators (Sahm Rule, Yield Curve, GDP, Unemployment, ADS Index) carry higher weights (8-15% each), while unofficial indicators (Lipstick, Stripper, Big Mac, Cardboard Box, etc.) carry lower weights (1-4% each). This ensures proven economic metrics have more influence than quirky indicators.

Result: The final score (0-100%) represents recession likelihood, with confidence intervals showing uncertainty based on data completeness. The breakdown shows which indicators contribute most to the current probability.
